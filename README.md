
# TaskFlow - Student Task Manager

TaskFlow is a student productivity web application that helps students organize their academic tasks, track deadlines, and monitor their progress.

## Features

- User Login and Sign Up
- Add and manage tasks
- Set task deadlines
- Set task priority
- Search tasks
- Filter tasks by status
- Track completed and pending tasks
- Progress tracking
- Supabase integration for authentication and data storage

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Configure your Supabase project.
4. Run the website using Live Server.
